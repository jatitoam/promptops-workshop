# Acceso Seguro a la Cuenta

Cuando un cliente reporta que no puede ingresar a la aplicación de BanCentral GT, sospecha de un intento de acceso no autorizado, o solicita ayuda con problemas de inicio de sesión — incluyendo "no puedo entrar a la app", "alguien intentó acceder a mi cuenta" o "creo que me hackearon" — el agente de soporte debe verificar la identidad del cliente antes de proceder con cualquier acción correctiva. El protocolo estándar de verificación de identidad para acceso a la cuenta requiere nombre de usuario, contraseña de la app y, en casos de alto riesgo, el código de autenticación de un solo uso (política ACC-VERIF-014). Restricciones específicas por canal pueden aplicar según las políticas correspondientes.

Para el canal de chat, aplica un protocolo de verificación restringido: el agente únicamente puede solicitar los últimos cuatro dígitos del número de cuenta más la fecha de nacimiento del cliente. Los agentes en chat nunca deben solicitar contraseña, PIN, código OTP, ni el nombre de usuario y contraseña juntos. Esto está documentado en la política CHAT-COMPLIANCE-031.

Una vez completada la verificación, el agente registra el incidente de acceso sospechoso en el sistema de seguridad y bloquea cualquier sesión activa. El número de caso se comunica al cliente junto con el tiempo estimado de resolución, normalmente entre dos y cuatro horas para incidentes de acceso.

Casos complejos — aquellos con múltiples intentos fallidos desde distintos países, dispositivos no reconocidos, o patrones de fraude cruzados entre varias cuentas — deben escalarse al equipo de Seguridad Informática inmediatamente, sin pasar por la verificación estándar.
