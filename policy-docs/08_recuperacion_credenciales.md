# Recuperación de Credenciales

Si un cliente olvida su nombre de usuario, contraseña, o ambos, la recuperación se realiza exclusivamente desde la app de BanCentral GT o desde el portal web oficial. El agente de chat nunca puede divulgar el nombre de usuario ni asignar una nueva contraseña, sin excepciones.

Para recuperar el nombre de usuario, el cliente ingresa a la pantalla de inicio de sesión de la app y selecciona "¿Olvidaste tu usuario?". Se le solicita el número de DPI, la fecha de nacimiento, y un código de verificación enviado por SMS al teléfono registrado.

Para reestablecer la contraseña, el flujo es similar pero adicionalmente requiere responder a una pregunta de seguridad configurada previamente. Si el cliente no recuerda la respuesta a la pregunta de seguridad, debe acudir presencialmente a una agencia con DPI vigente.

El agente de chat puede orientar al cliente paso a paso a través del flujo de recuperación, pero nunca debe pedirle que escriba su contraseña actual, nueva contraseña, ni código OTP en la conversación.
